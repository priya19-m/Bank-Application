## Problem Statement
The objective of this project is to design and implement a Bank Account Management System using Java with an object-oriented approach.
## The system allows:
1. Creating and managing customer bank accounts.
2. Performing core banking operations:
      Deposit, Withdrawal, Balance inquiry
3. Maintaining account details such as account number, customer name, and current balance.
4. Applying validation (e.g., minimum balance check, invalid account number).
5. Handling exceptions for insufficient balance, invalid operations, and missing accounts.
6. Displaying transaction updates and maintaining clean console-based interaction.
7. Ensuring modular design using OOP concepts (Encapsulation, Inheritance, Polymorphism).
## How to Run in Eclipse IDE
Step 1: Open Eclipse IDE
Download from: https://www.eclipse.org/downloads/
Step 2: Create a New Project
Go to File → New → Java Project
Enter project name: BankApplication
Click Finish
Step 3: Create Packages
Right-click on src → New → Package
Create these packages:
com.wipro.bank.bean
com.wipro.bank.dao
com.wipro.bank.service
com.wipro.bank.util
com.wipro.bank.main
Step 4: Add Classes
Inside each package, create corresponding .java files.
Copy-paste all program files into these packages:
TransferBean.java, BankDAO.java, BankMain.java, BankService.java, DBUtil.java, InsufficientFundsException.java
Step 5: Run the Main Class
Go to com.wipro.bank.main → BankMain.java
Right-click → Run As → Java Application
